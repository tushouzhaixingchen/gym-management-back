健身房管理系统 API 文档
版本：v1.0
基础地址：{{baseURL}} (请替换为实际服务器地址，如 http://localhost:8080)
认证方式：Bearer Token (登录后在 Header 中携带 Authorization: Bearer <token>)

================================================================================
一、认证模块 (Auth)
================================================================================

1. 用户登录
   接口地址：/api/auth/login
   请求方式：POST
   描述：获取访问令牌 (Token)
   
   请求参数 (Body):
   {
     "account": "hunter",      // 账号
     "password": "123456"      // 密码
   }
   
   响应说明：
   成功时返回 data.token，后续请求需在 Header 中携带该 Token。

================================================================================
二、管理员管理 (Admins)
================================================================================

1. 获取管理员列表
   接口地址：/api/admins
   请求方式：GET
   
2. 获取管理员详情
   接口地址：/api/admins/{id}
   请求方式：GET
   路径参数：id (管理员ID，示例中为 4)

3. 新增管理员
   接口地址：/api/admins
   请求方式：POST
   请求参数 (Body):
   {
     "username": "hunter",
     "password": "123456",
     "realName": "普通管理员",
     "roleId": 2,
     "storeId": 2,
     "phone": "13800138089",
     "email": "test@gym.com"
   }

4. 编辑管理员
   接口地址：/api/admins/{id}
   请求方式：PUT
   路径参数：id (管理员ID，示例中为 4)
   请求参数 (Body):
   {
     "id": 4,
     "realName": "李四修",
     "roleId": 2,
     "storeId": 1,
     "phone": "13800138001",
     "email": "zhangsan_new@gym.com"
   }
   *注：虽然路径中有ID，但示例Body中也包含了id字段，请以实际后端要求为准。

5. 删除管理员
   接口地址：/api/admins/{id}
   请求方式：DELETE
   路径参数：id (管理员ID，示例中为 6)

三、会员管理 (Members)
================================================================================

1. 获取会员列表
   接口地址：/api/members
   请求方式：GET
   查询参数：
   - page: 页码 (默认1)
   - size: 每页数量 (默认10)
   - status: 会员状态

2. 获取会员详情
   接口地址：/api/members/{id}
   请求方式：GET
   路径参数：id (会员ID)

3. 新增会员
   接口地址：/api/members
   请求方式：POST
   请求参数 (Body):
   {
     "realName": "张三测试5",
     "phone": "13800138094",
     "gender": 1,             // 1:男, 2:女
     "idCard": "110101199001011234",
     "registerStoreId": 1,
     "remark": "Postman 自动化测试创建",
     "joinDate": "2025-09-08",
     "cardType": "period"     // 卡类型
   }

4. 编辑会员
   接口地址：/api/members/{id}
   请求方式：PUT
   路径参数：id (会员ID)
   请求参数 (Body):
   {
     "realName": "张三修改",
     "phone": "13800138099",
     "gender": 2,
     "remark": "Postman 测试修改备注"
   }

5. 删除会员
   接口地址：/api/members/{id}
   请求方式：DELETE
   路径参数：id (会员ID)

6. 会员签到
   接口地址：/api/members/{id}/check-in
   请求方式：POST
   路径参数：id (会员ID)
   请求参数 (Body):
   {
     "memberId": 1,
     "storeId": 1,
     "checkInMethod": "qrcode", // 签到方式
     "remark": "前台扫码签到"
   }
